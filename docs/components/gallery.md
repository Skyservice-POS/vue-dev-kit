# Галерея компонентів

Усі компоненти кіта на одному екрані — живі, клікабельні, у фірмовому стилі. Зручно показати команді, що вже є, і не писати з нуля те, що вже написано.

Назва кожної картки веде на сторінку компонента з props, подіями, слотами й CSS-змінними.

<ClientOnly>
  <ComponentGallery />
</ClientOnly>

## Як цим користуватись

1. **Знайшли потрібне** — перейдіть за назвою картки на сторінку компонента.
2. **Скопіювали приклад** — на кожній сторінці є готовий фрагмент із кнопкою копіювання.
3. **Підключили** — усе імпортується з кореня пакета:

```ts
import '@skyservice-developers/vue-dev-kit/style.css'
import { SkyButton, SkyDataTable, Modal } from '@skyservice-developers/vue-dev-kit'
```

Кастомізація кольорів і відступів — через [CSS-змінні](/guide/theming), без форків і перевизначення класів.
